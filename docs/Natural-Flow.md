# Tactile flow

Cube uses the 180 stiffness, 20 damping, 1 mass spring selected in
Eight-Characters and adopted by Poise and eightchord-com. `src/motion.js`
retains position and velocity on reversal and owns completion by the latest
request. Control feedback uses 100 ms ease-out. Logical close, input, focus,
market values and direct chart gestures stay immediate.

The shared runtime supplies arrivals, inert visual departures, retained actor
layout, intrinsic disclosure sizing, reversible panel visibility and bounded
guided scrolling. Reduced motion, resize, printing, hidden documents and page
departure release temporary presentation. Native dialogs retain native modal,
focus and Escape semantics; supporting browsers retain their visual exit.

Coverage and regression evidence for the complete pass are recorded here as
its existing surfaces are connected. The tracking issue is #136.
